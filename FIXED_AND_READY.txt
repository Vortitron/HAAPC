🚀 HOW TO USE ON YOUR CLOUD SERVER
───────────────────────────────────────────────────────────────────

1. COPY TO HOME ASSISTANT
   └─ sudo cp -r custom_components/apc_pdu /config/custom_components/

2. RESTART HOME ASSISTANT
   └─ Settings → System → Restart

3. ADD DEMO PDU
   Settings → Devices & Services → Add Integration → "APC PDU"
   
   ┌─────────────────────────────────────────────┐
   │ IP Address: 192.168.1.100 (any value)      │
   │ SNMP Community: demo (any value)            │
   │ Device Name: Demo PDU (optional)            │
   │ SNMP Version: 1                             │
   │ Demo Mode: ✅ CHECK THIS!                   │
   └─────────────────────────────────────────────┘

4. DONE! 
   You now have a working PDU with 8 outlets to test with!
